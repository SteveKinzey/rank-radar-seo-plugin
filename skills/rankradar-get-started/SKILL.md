# Get started with RankRadar SEO

Briefly explain the workflow: public-site SEO review, mobile and desktop PageSpeed evidence, transparent scoring, and prioritized Markdown/PDF reports when the host has the required tools.

Give this example prompt: "Run an SEO report on https://example.com/ with mobile and desktop PageSpeed results and downloadable Markdown and PDF reports."

If the user already supplied a real target and requested an audit, use rankradar-seo and begin the work instead of asking again. Otherwise ask only for the target URL; audience/location/business goals are optional context.

Explain that this is a skills-based plugin using the host's available research, browser, execution, and file tools. Missing tools or measurements are disclosed. This package has no hosted audit service, no automatic account credentials, and no remote bridge to local Command Code. Supplied Command Code findings can be reviewed and merged; automatic local execution belongs to the separate local desktop skill installation.

Do not claim the plugin is installed on another person's account, publicly listed, or tested on a target without evidence. Do not install dependencies, change billing, or request account secrets as part of onboarding.
